# Contributing

Use a local environment with Python 3.11 or 3.12. On Windows, verify the Tk installation with **python -m tkinter**. Run **python -B -m unittest discover -s tests -v** and start the GUI with **python -B desktop.py --demo**.

Use invented titles, paths, identifiers and messages for examples and tests. Generate files on demand with the fictional profile builder. Keep real logs, screenshots, ZIP backups, credentials and workspace paths out of every Git object.

Preserve a filesystem-only read boundary for Antigravity data. SQLite may open isolated copies. New decoders should identify their known format and report incomplete coverage when evidence is insufficient.

For a Windows build, install **requirements-build.txt** in a build environment and run **python scripts/build_windows.py**. Review **docs/RELEASE_CHECKLIST.md** with the release artifact. Add a regression test for changes to data safety or completeness.
