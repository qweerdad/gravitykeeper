# Privacy

The app has no login, telemetry, update checker, external API calls, or cloud upload. Command output, settings, snapshots, exports, ZIP files, and searches remain on the computer unless you move them.

Source discovery is limited to selected, local Antigravity session paths and installation file metadata. It excludes account stores, browser stores, cookies, credentials, global mixed settings, link targets and sensitive filenames. Database checks use duplicated files. The app can be used while Antigravity is running.

Conversations and tool logs may already include sensitive text, terminal output, paths and private media. GravityKeeper preserves recognized content for recovery. It does not silently redact messages or encrypt exports. Choose local private storage with appropriate permissions and avoid unintended cloud sync.

Desktop preferences live in the Windows user's local application data folder. The preferences contain the source override, backup location, and language. Demo mode builds a fictional profile and does not read the installation or session directories.

The project repository, CI test inputs, release files and screenshots use source code or fictional data. A normal app snapshot is private user output and does not belong in Git or public bug reports.
